# Can a Fresher Afford Bengaluru?

## About the Project
As someone living in Bengaluru, I always wondered can a fresher actually afford to live AND enjoy this city on an entry level salary? This project answers that question using real data!

## Tools Used
- *Python (Google Colab)* — data cleaning and charts
- *SQL* — querying insights from data
- *Excel* — pivot tables and dashboard
- *Power BI* — interactive 4-page dashboard

## Datasets Used
- Zomato Bangalore Restaurants (209 restaurants)
- Bangalore House Rent data (1080 localities)
- Software Professional Salaries — Bangalore (22,000+ records)

## Key Findings
- Average monthly rent in Bengaluru: ₹23,183
- A fresher earning ₹35,000/month has only ₹5,000 left after basic expenses!
- Most popular cuisine: Biryani and North Indian
- Most expensive areas to eat: Forum Mall, ITC Gardenia
- Top paying job: Front End Developer
- Cheapest areas to live: Electronic City, Whitefield

## Project Structure
- Colab notebook — data cleaning, SQL queries, charts
- Excel dashboard — pivot tables and KPI metrics
- Power BI dashboard — 4 interactive pages
